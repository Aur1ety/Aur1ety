**ROENTGEN** &nbsp; <img src="https://img.shields.io/badge/FLAGSHIP-E8FF4D?style=flat-square&labelColor=1F1F1F"/> <img src="https://img.shields.io/badge/PRIVATE%20REPOSITORY-2E2E2E?style=flat-square&labelColor=2E2E2E"/>

<sub><code>SOLAR FLARE NOWCASTING + 24-HOUR FORECASTING</code></sub>

An end-to-end solar-flare system built from X-ray telemetry and active-region features. Twin temporal convolutional networks nowcast the live flare state, a calibrated gradient-boosted ensemble estimates major-flare probability over the next 24 hours, and a task router combines their outputs.

On SWAN-SF, the forecasting system reached **TSS 0.811** under a leakage-audited, out-of-time evaluation. The live pipeline also matched **17 of 17** events in NOAA's official flare list during a one-week test.

<a href="https://github.com/Aur1ety/Einthoven-model-for-cardiac-arrhythmia-and-pathology-detection"><strong>EINTHOVEN</strong></a>

<sub><code>ECG CLASSIFICATION + DATASET AUDIT</code></sub>

A controlled PTB-XL study comparing raw 12-lead ECGs with reconstructed 3-D vectorcardiograms. A 1-D ResNet reached **macro-AUC 0.930**, while VCG augmentation produced no measurable improvement. A dataset-wide lead-consistency audit checked all **21,799 recordings** and flagged 57 for review.

<a href="https://github.com/Aur1ety/NeuroPHarma-Drug-sequencer"><strong>NEUROPHARMA</strong></a>

<sub><code>DRUG–DRUG INTERACTION EXPLORER</code></sub>

A React/FastAPI platform that keeps curated interaction evidence separate from model-generated estimates.
